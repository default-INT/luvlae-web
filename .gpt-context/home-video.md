- Cloudflare [Static Assets limits](https://developers.cloudflare.com/workers/platform/limits/) allow 25 MiB per file. Only the two video paths use runWorkerFirst. `_app/cloudflare/video-assets.ts` fetches ASSETS and supplies full/HEAD/206/416 responses with correct MIME and byte ranges. Requests to these paths invoke the Worker and incur the account's Worker request usage. Other assets retain their existing routing.
- `tests/video-assets.test.ts` covers initial-byte probes, open/suffix ranges, invalid requests, HEAD/full MIME/size and the 25 MiB artifact limit. Chrome localhost verified autoplay, pause/resume and mute/unmute. A local stage Vite/Cloudflare build passed, and generated assets.runWorkerFirst contains both video paths. Deployed Safari and actual Lighthouse LCP remain separate checks. No metadata, canonical, robots, sitemap or structured-data changes were needed for the film; existing homepage text stays server-rendered.
